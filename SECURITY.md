# Security policy

DODGEBORN is a static browser game without accounts or a server. Security reports should include the affected version, reproduction steps, and impact. Once a public repository exists, use its private vulnerability reporting channel if available; otherwise contact its maintainers through a private channel before publishing exploit details. No security contact address has been assigned yet.

Do not include credentials or personal data in bug reports. Dependency updates and browser compatibility changes should be verified through the project test and build commands.
