# 技術與設計決策

1. 使用 npm workspaces，分開瀏覽器畫面、純模擬核心、集中數值與共用型別。模擬核心可直接在 Node.js 執行。
2. 固定 60Hz 模擬，使用掃掠線段與圓形受擊區偵測高速球。攻擊 ID 保證每次有效攻擊對同一角色只扣一次 HP。
3. 球權 held/free/flight、角色狀態及比賽 finished 分開管理。內野有 HP，外野只參與攻防；180 秒逾時比較剩餘內野 HP。
4. 必殺由助跑、跳躍與出手時機啟動，沒有魔力條或必殺冷卻。六技能各有實際碰撞、傷害、軌跡與接球／閃避反制。
5. AI 使用有限狀態和效用分數。反應間隔、守備機率、準度及進攻節奏由難度資料控制，決策只看目前球與球員狀態。
6. 480×270 邏輯畫布及整數倍率優先。原創程序化像素角色、球場、Web Audio 背景音樂與合成音效不依賴第三方素材。
7. Canvas 2D 是目前可玩的渲染器。Phaser 4.2.1 僅列為預定依賴；完成正式工具鏈驗證後，再評估是否值得遷移。
8. 保留可玩的 Canvas 基準版本，避免在正式測試與封包流程穩定前替換渲染器。
9. `build:local` 使用 Node.js 內建 TypeScript 語法移除，提供可執行的靜態產物；它不能做型別檢查。`npm run build` 保留 TypeScript＋Vite 正式路徑。
10. 本機 Chrome 煙霧測試以路由攔截提供專案檔案；CI 預定測 Chromium、Firefox、WebKit。這些測試均不取代正式跨瀏覽器驗收。
11. 離線可攜版將原創 Canvas 程式、樣式與背景音樂合入單一 HTML，壓縮為不含依賴與安裝腳本的 ZIP；CSP 禁止外部連線，SHA-256 協助完整性檢查。它不是簽署過的原生安裝程式。
12. 公開來源採白名單匯出為乾淨快照，不直接推送含機器路徑的舊 Git 歷史；來源 ZIP 排除 `.git`、快取、建置產物和憑證。
13. Vercel 示範站採 Node 22.x 的靜態 `build:local` 輸出，略過不必要的依賴安裝；部署由使用者在 Vercel 網頁匯入 GitHub 倉庫後執行，取得真實網址後再更新 README。
