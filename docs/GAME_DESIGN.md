# 遊戲設計與規則

- 六對六：每隊三內野、三外野。只有內野 HP 參與勝負，三名內野全滅即輸。
- 固定 60Hz。比賽最長 180 秒；逾時依剩餘內野 HP 決勝，同分為平局。
- 球權為球的 held/free/flight 狀態，與角色動作及比賽結束狀態分離。傳球飛行不造成傷害。
- 高速球以每一 tick 的線段與球員圓形受擊區做連續碰撞。相同攻擊 ID 對同一角色只會造成一次傷害。
- 助跑累積動能後於空中投球觸發角色必殺。主要限制是球權、位置與出手時機，沒有魔力條或必殺冷卻。
- 烈焰高速直線；雷電於第 13 tick 轉向；疾風蛇行；幻影包含一實球兩假球；重力命中帶有小範圍爆震；流星有三顆真實彈幕。真球均可藉接球或閃避反制。
- 接球有短時間判定窗；完美接球令下一次投球增傷。閃避有短暫無敵幀。倒下後玩家接手下一名存活內野隊友。
- AI 使用有限狀態（防守、尋球、攻擊、接球、閃避）與效用分數，依當下可觀察的球速與位置決策。難度改變反應間隔、判斷成功率、準度與出手節奏，不讀取未來玩家輸入。

畫面採 480×270，優先整數倍率；角色、球場、特效與音效以原創程序化首版素材呈現。後續可替換為逐幀像素美術，但須保留清楚的攻防判讀。
